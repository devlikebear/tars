## 흐름 요약

### 1. `cmd/tars/main.go` 분석

**진입점 한눈에:**

```go
func main() {
    bootstrapEnv()
    exitCode := 0
    runOnMainThread(func() {
        if err := newRootCommand(...).Execute(); err != nil { ... }
    })
    os.Exit(exitCode)
}
```

핵심 포인트:

1. **`bootstrapEnv()`** — `envloader.Load(".env", ".env.secret")`. 두 파일 분리 패턴: `.env`는 커밋, `.env.secret`은 gitignore.
2. **`runOnMainThread(...)`** — OS별 분기(`mainthread_darwin.go` / `mainthread_other.go`). macOS는 일부 시스템 콜이 메인 스레드에서만 동작해야 해서 필요.
3. **`os.Exit`은 클로저 밖** — defer가 정상 실행되도록 하기 위함.

**`newRootCommand` 구조:**

- Cobra 패턴, root + 14개 서브커맨드.
- root 자체 `RunE`는 인자 없이 `tars`만 쳤을 때 두 분기:
  - `--message` 있으면 → **client 모드** (다른 tars 서버에 메시지)
  - 없으면 → **console 모드** (브라우저 콘솔)

**눈에 띈 패턴:**

```go
import _ "github.com/devlikebear/tars/internal/browserplugin" // register browser plugin
```

`_` 사이드이펙트 import → 패키지 `init()`에서 자기 자신을 레지스트리에 등록. 이게 다음 조사의 출발점.

### 2. browserplugin 추적

**의문**: 이게 잔재인가? 사용자가 과거에 일부 플러그인 코드를 삭제한 기억이 있음.

**확인**:

- `git log --oneline -- internal/browserplugin/` → PR #190 "extract browser into built-in plugin system (Phase 2)" (2026-03-29). 적극적으로 도입된 활성 코드.
- 사용자 메모리(`project_plugin_system_v2.md`) → 해당 PR이 포함된 #188 마일스톤 전체 완료 상태.
- CLAUDE.md → 삭제된 건 `internal/project/*` (#15-#259, removed in #291-#347). browserplugin은 살아남음.

**구조**:

- `register.go`: `init()` 한 줄 — `plugin.RegisterBuiltin(&Plugin{})`
- `plugin.go`: `Plugin` struct가 `plugin.BuiltinPlugin` 인터페이스 구현
  - `Definition()` — 메타데이터 + HTTP 라우트 6개 (`/v1/browser/status`, `/v1/browser/profiles`, `/v1/browser/login`, `/v1/browser/check`, `/v1/browser/run`, `/v1/vault/status`)
  - `Init(ctx)` — config에서 vault/OTP 의존성 주입받아 `browser.Service` 생성
  - `Close()` — 정리

**결론**: 잔재 아님. 그러나 CLAUDE.md의 새 가이드라인(`skill + CLI` 우선)과 **충돌하는 레거시**로 분류 → [TN-001](../findings/tensions.md#tn-001) 등록.

## 던진 질문 (대화 기록)

- **Q (assistant → user)**: `_` import + `init()` 등록 패턴의 함정 — (1) 등록 순서가 import 그래프에 암묵적으로 종속, (2) zero-value 등록과 실제 초기화(`Init`) 시점 분리로 "등록됐지만 비활성" 상태가 가능. → 이 부분은 `internal/plugin/`을 봐야 깊이 답할 수 있음. 다음 세션 후보.
