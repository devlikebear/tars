### Exponential backoff (helpers.go:36-54)

```go
base := 30 * time.Second
if interval := parseEveryDuration(schedule); interval > base {
    base = interval  // schedule interval 보다 작은 base 안 씀
}
multiplier := min(failures-1, 6)  // cap 6 → 64x
backoff := base * (1 << multiplier)
return min(backoff, 12 * time.Hour)
```

→ 30s → 60s → ... → 12h cap. **crash-resistant**. CLAUDE.md *"crash-resistant idempotence"* 정렬.

### Natural language schedule fallback

```go
func normalizeSchedule(raw string) (string, error) {
    if normalized, err := scheduleexpr.NormalizeExpression(raw); err == nil {
        return normalized, nil
    }
    if natural, err := scheduleexpr.ParseNaturalSchedule(raw, "", time.Now().UTC()); err == nil {
        return natural, nil
    }
    return "", err
}
```

→ cron expression 실패 시 *"내일 9시"*, *"매일 오전 9시"*, *"every Monday at 10am"* 같은 자연어 fallback. **사용자 친화**.
