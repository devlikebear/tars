## 패키지 한눈에

CLAUDE.md 약속과 **거의 100% 일치**하는 모범 패키지:

- `pulse` = **시스템 surface 워치독**. 1분 틱마다 5 도메인(cron / gateway / disk / delivery / reflection) 신호 수집 → 임계값 초과 시 LLM에게 분류 요청 → ignore / notify / **whitelisted autofix**.
- LLM은 **분류기 only** (`pulse_decide` 단일 도구, ToolChoice required)

## 흐름 요약

### types.go (145줄)

5 핵심 타입: `Severity`(4단계), `SignalKind`(5종), `Signal`, `Action`(3종), `Decision`, `TickOutcome`. **패키지 doc(L1-13)이 architecture를 한 페이지로 설명** — 다른 패키지 doc의 모범.

### state.go (126줄)

Ring buffer + 카운터 5종 + nil-tolerant. **defensive copy** for Decision (race 방지).

### notify.go (93줄)

`NotifyEvent` (transport-neutral) → `Notifier` 인터페이스 1 메서드. severity floor + ActionNotify만 통과. nil notifier 허용.

### runtime.go (327줄) — 라이프사이클 핵심

- `Config` + 헬퍼로 default 적용 (interval 1m, decider timeout 2m)
- `Dependencies` 5 collaborators **모두 nil 허용** — 점진 wiring 가능 (RF-006의 telegram counter wiring 점진성을 자연스럽게 받아낼 수 있음)
- `Start/Stop`: race-free (close + drain 패턴)
- **`runTick` 4단계**:
  1. Active hours gate
  2. Scan signals (0건이면 LLM skip = 비용 절감)
  3. Decide with timeout (hung LLM이 다음 tick 안 막음)
  4. Act (ignore / notify / autofix)
- `withinActiveHours`: wrap-around 윈도우(예: 22:00-02:00) 지원

→ [RF-014](../findings/refactor.md#rf-014) 발견: silent fallback 패턴 (parseActiveHours 코멘트가 "no silent fallback" 자랑하는데 호출자가 silently fallback). 보호는 정당, 로그/검증 추가 권장.

### signal.go (348줄) — narrow interfaces 모음

CLAUDE.md 약속의 5 narrow Go interfaces가 **한 파일에 모여 정의**:

```
CronJobLister, GatewayRunLister, DiskStatProvider,
DeliveryFailureCounter, ReflectionHealthSource
```

각 인터페이스에 *"real implementor satisfies it"* 코멘트 — 양방향 추적. `ReflectionHealthSource` 코멘트는 *"without importing pulse in reverse"* 명시 (순환 의존 회피).

`Thresholds` 7 임계값, **0 = disabled** (enum 없이 단순). `Scanner.Scan()` 5 함수 같은 형태로 fan-out. 한 소스 실패가 tick 전체 abort 안 함 (silent nil — RF-014와 같은 카테고리).

### decider.go (220줄) — LLM 분류기 + 3중 방어

```go
client.Chat(ctx, messages, llm.ChatOptions{
    Tools:      []llm.ToolSchema{PulseDecideToolSchema()},   // 도구 1개만
    ToolChoice: "required",                                   // 반드시 호출

```

System prompt 단호: *"Your ONLY job is to call the pulse_decide tool ... Do not call any other tools."*

`router.ClientFor(RolePulseDecider)` 매 호출마다 → **runtime model retargeting** (config 한 줄 수정으로 모델 변경, 재시작 불필요).

## 패키지 인사이트

pulse는 **이 코드베이스의 모범 패키지**. 특징:

1. **CLAUDE.md 약속과 100% 일치** — 코드와 문서 sync
2. **분류 ≠ 실행** 원칙이 보안의 핵심
3. **Narrow interfaces** 패턴이 한 파일에 정리되어 다른 패키지 wiring 시 베이스로 사용 가능
4. **fail-soft** 일관성 (silent fallback) — 단점이 있지만 RF-014로 작은 개선만 필요
5. **autofix 4 속성** 패키지 doc — 새 autofix 추가 시 가이드 역할

다른 패키지 리팩토링 시 참고할 만한 모범. 특히:

- 패키지 doc 스타일 (다른 패키지에 누락 많음 — 향후 ID 후보)
- nil-tolerant Dependencies 패턴
- LLM을 분류기로 좁히는 패턴 (다른 LLM 호출 영역에 적용 가능)
