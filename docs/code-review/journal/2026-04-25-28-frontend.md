## 좋은 패턴 ⭐

### 1. Shared EventSource pattern (api.ts:570-626) ⭐⭐

```ts
let sharedStream: EventSource | null = null
let listeners = new Map<number, EventListener>()

function ensureStream() {
    if (sharedStream && sharedStream.readyState !== EventSource.CLOSED) return
    sharedStream = new EventSource('/v1/events/stream')
    // broadcast to listeners
}

function maybeCloseStream() {
    if (listeners.size === 0) { sharedStream.close(); sharedStream = null }
}
```

→ **여러 component 가 SSE 공유**. EventSource 연결 수 제한 (브라우저 default 6) 방지. listener 0 → 자동 close. **모범 패턴**.

### 6. requestJSON<T> wrapper

```ts
async function requestJSON<T>(input: string, init?: RequestInit): Promise<T> {
    const response = await fetch(input, ...)
    if (!response.ok) {
        const payload = await response.json() as APIErrorPayload
        throw new Error(payload?.error?.trim() || ...)
    }
    if (response.status === 204) return undefined as T
    return await response.json() as T
}
```

→ 모든 API 호출의 표준 wrapper. APIErrorPayload 처리 + 204 No Content + type-safe.
