## 좋은 패턴 ⭐

### 1. Run lifecycle 분리 (4 단계)

```go
Spawn (req) →
  newAcceptedRunState (lock 안 잡음, ctx + cancel + done channel 생성) →
  registerAcceptedRunState (lock + map 등록 + WG add + persist + event publish) →
  go executeRun (백그라운드 실행 + finalizeRunLocked)
```

→ 각 단계 책임 분리 명확. lock 잡는 곳/안 잡는 곳 명시. **모범 패턴**.

### 2. AgentExecutor 인터페이스 + 2 구현체

```go
type AgentExecutor interface {
```

### 3. CommandExecutor 의 metadata env injection 가드

```go
func sanitizeMetadataEnvValue(raw string) (string, bool) {
    trimmed := strings.TrimSpace(raw)
    if trimmed == "" { return "", false }
    for _, r := range trimmed {
        if r < 0x20 || r == 0x7f {  // control char
            return "", false
        }
    }
    return trimmed, true
}
```

→ TARS_RUN_ID/TARS_SESSION_ID 등 env 에 control char 들어가는 injection 방지. **보안 가드 8번째**.
