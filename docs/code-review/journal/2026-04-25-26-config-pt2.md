### applyLLMPoolDefaults — kind-specific defaults (defaults_apply.go:318-449)

각 kind 별:
- `openai`: BaseURL=https://api.openai.com/v1, APIKey=$OPENAI_API_KEY
- `openai-codex`: BaseURL=https://chatgpt.com/backend-api, APIKey=$OPENAI_CODEX_OAUTH_TOKEN, **api-key 없으면 oauth 자동 promotion**
- `claude-code-cli`: AuthMode=cli (CLI 자체 credential)
- `gemini`/`gemini-native`: GEMINI_API_KEY 자동 fallback
- `anthropic`: ANTHROPIC_API_KEY 자동 fallback

→ **사용자 minimum config**. 한 줄 (`kind: anthropic`) 만 적어도 동작. CLAUDE.md *"new users get a working baseline after setting ANTHROPIC_API_KEY"* 정렬.

### RF-065 — `yaml_paths.go` 200+ switch — DRY 위반, 5 곳 동기화

새 config field 추가 시:
1. types.go (struct field)
2. defaults.go (constant)

→ **silent skew 위험**. yaml_paths.go 빠뜨려도 컴파일 통과 (콘솔 UI nested 출력만 안 됨).

→ **configInputField 에 `preferredPath` 필드 추가**. yaml_paths.go 제거 가능. **DRY 강화**.

### RF-066 — `applyLLMPoolDefaults` kind switch — 새 provider 추가 시 5 곳 반복

새 provider 추가 시:
1. defaults.go (constant)
2. defaults_apply.go (kind switch)
3. defaults_apply.go:defaultOAuthProvider
4. internal/llm/provider.go (NewProvider switch)

→ **provider registry pattern** 으로 통합. `providerKinds` map = 단일 source. ID-004 (capability 메타 추가) 와 결합 가능.
