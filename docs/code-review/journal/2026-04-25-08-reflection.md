### state.go (163줄)

Ring buffer (default 14 = "two weeks of nightly runs") + 5 카운터. **`MarkAttemptStarted`** crash-recovery 패턴:

```go
if s.lastRunAt.Before(now) {
    s.lastRunAt = now    // 잡 시작 전에 미리 push
}
```

→ 프로세스 crash 시 다음 tick 즉시 재실행 방지. RecordRun이 나중에 정확한 finish time으로 덮어씀. **야간 배치 모범**.

`ConsecutiveFailures()` + `LastRunAt()` — pulse의 `ReflectionHealthSource` 인터페이스 자연스럽게 만족 (순환 의존 회피).

## 핵심 비교 — pulse vs reflection

| 측면 | pulse | reflection |
|------|-------|-----------|
| Surface | system | system (other half) |
| 주기 | 1분 tick | 5분 tick (sleep window 안에서만 실행) |
| LLM 도구 표면 | 1 (`pulse_decide`) | 0 (Chat 직접 호출) |
| 결정 주체 | LLM 분류기 | deterministic (sleep window + anchor day) |
| 실행 | autofix whitelist 또는 notify | 잡 순차 실행 |
| 실패 처리 | tick 단위 격리 | 잡 단위 격리, **panic recovery 추가** |
| 잘못된 윈도우 | silent always-active | strict skip with reason |
| Crash recovery | (해당 없음) | `MarkAttemptStarted` 패턴 |
