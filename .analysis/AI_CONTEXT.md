## Module Summary

- `cli-client`: `cmd/tars` is the thin Cobra entry point; root opens the console or sends one-shot chat, and subcommands call server APIs through `pkg/tarsclient` / `internal/tarsclient`.
- `tarsserver`: `internal/tarsserver` composes config, LLM router, sessions, tools, cron, pulse, reflection, agent runtime, ops, and console static serving into one HTTP mux.
- `agentruntime`: `internal/agentruntime` manages async run lifecycle, executor registry, workspace agents, channels, persistence, and run events.
- `memory`: `internal/memory` plus chat memory hooks manage long-term memory, semantic search, daily logs, experiences, and compaction context.
- `system-surfaces`: Pulse, Reflection, and Ops are separated from user chat/tool surfaces and use narrow Go interfaces for operational work.
- `extensions`: Skill, Plugin, MCP, and Skill Hub keep feature loading on-demand instead of inflating the core prompt/tool surface.
- `frontend-console`: `frontend/console` is the Svelte 5 UI for Chat, Memory, System Prompt, Ops, Pulse, Reflection, Extensions, and Config.
